# Exercícios de Fundamentos de Java

> Os exercícios foram reunidos em [estudos-programacao](https://github.com/jhonmnf/estudos-programacao/tree/main/java/fundamentos). Novos exercícios devem ser adicionados ao repositório central; este repositório preserva a origem do material.

Exercícios de Java com exemplos de variáveis, operações e saída no terminal. O código está organizado como projeto Eclipse na pasta `meuprojeto2/`.

## Executar um exercício

Com um JDK instalado, execute a partir da raiz do repositório:

```bash
cd meuprojeto2
javac -encoding UTF-8 -d out src/meuprojeto/Codigo1.java
java -cp out meuprojeto.Codigo1
```

Para estudar os outros exemplos, escolha uma das classes `Codigo2` a `Codigo12` e confira se possui método `main` antes de executá-la.

## Estrutura

- `meuprojeto2/src/meuprojeto/`: exercícios e classe `Matematica`.
- `meuprojeto2/src/module-info.java`: declaração do módulo.
- `meuprojeto2/.project` e `.settings/`: configuração do Eclipse.
